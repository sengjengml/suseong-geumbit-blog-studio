# 수성금빛부동산 블로그 스튜디오

부동산 공인중개사가 네이버 블로그용 정보성 원고를 단계별로 작성·검토하는 Windows 친화적 로컬 웹앱입니다. 특정 검색 순위나 노출을 보장하지 않습니다.

## 설치와 실행 (Windows 11)

PowerShell에서 다음 명령을 실행합니다.

```powershell
cd "C:\Users\sjm22\OneDrive\문서\ai\4주차\landlanguage-blog-studio"
npm install
npm run dev
```

Chrome 또는 Edge에서 `http://localhost:5173`을 엽니다. 로컬 API는 `127.0.0.1:8787`에만 바인딩됩니다.

더 간단한 방법은 프로젝트 폴더의 **`수성금빛부동산 실행.bat`**를 더블클릭하는 것입니다. `index.html`을 직접 더블클릭하면 Vite가 실행되지 않아 안내 화면만 나타납니다.

## 주요 기능

- Step 1: 작성자·주제·키워드·강조사항·경험·출처·중개사 프로필 입력
- Step 2: 제목 3안과 8구간 아웃라인 생성·편집·순서 변경
- Step 3: 기준일, 비교표, FAQ, 출처 및 미확인 자리표시가 포함된 원고 생성
- 프롬프트 복사·외부 AI 결과 붙여넣기 대체 모드
- 글자 수와 표시용/UTF-8 바이트 계산, 미완성 칸 복사 경고
- 내부 품질 평가 9항목(총 100점), 보완안 반영
- localStorage 보관함, TXT/HTML/JSON 내보내기, SVG 정보카드 저장
- 라이트/다크 테마, 반응형 UI

## AI 연결과 비용

기본값은 `prompt-only`입니다. API 키나 CLI가 없어도 프롬프트를 복사해 외부 AI에서 실행하고 결과를 붙여넣을 수 있습니다. OpenAI·Anthropic API 자동 호출과 Codex CLI 자동 실행 어댑터는 현재 연결하지 않았습니다. ChatGPT/Claude 구독과 API 사용료는 별개일 수 있습니다. API 키는 브라우저나 localStorage에 저장하지 마세요.

## 저장 위치와 보안

초안과 보관함은 현재 브라우저의 localStorage에 저장됩니다. 중요한 원고는 프로젝트 JSON으로 내보내 별도 보관하세요. 네이버 계정, 쿠키, 비밀번호는 수집하지 않으며 자동 발행은 지원하지 않습니다.

## 외부 자료와 최신 뉴스

뉴스 검색 연동이 없어 가짜 기사 목록을 만들지 않습니다. 사용자가 입력한 참고 자료만 사용합니다. 기사 내용은 참고 데이터로 취급하고 그 안의 명령을 실행하지 않습니다. 동일 폴더에 `블로그포스팅 프롬프트.txt`가 없었으므로 추가 가이드 1~13번은 반영하지 않았습니다.
